# 📖 User Guide — Stellar Contributor Recognition Platform

## Getting Started

### Step 1: Install a Stellar Wallet
Choose one of the four supported wallets:

| Wallet | Link | Best For |
|---|---|---|
| **Freighter** | [freighter.app](https://freighter.app) | Beginners — official SDF wallet |
| **Albedo** | [albedo.link](https://albedo.link) | No install needed — web-based |
| **xBull** | [xbull.app](https://xbull.app) | Soroban power users |
| **Rabet** | [rabet.io](https://rabet.io) | Chrome extension users |

### Step 2: Fund Your Wallet (Testnet)
1. Open the platform at [contributor-recognition-platform.vercel.app](https://contributor-recognition-platform.vercel.app)
2. Connect your wallet using the "Connect Wallet" button
3. Click **"Get Test XLM (Friendbot)"** in the Wallet Card to receive free testnet XLM

### Step 3: Add Contributors
1. Click the **"My Contributors"** tab
2. Click **"Add Contributor"**
3. Enter the contributor''s Name, GitHub username, and Stellar public key
4. Click Save

### Step 4: Send a Reward
1. Click a contributor row to select them
2. Click **"Send Reward"** tab
3. Enter the XLM amount and an optional memo
4. Click **"Execute Reward via Soroban"**
5. Approve the transaction in your wallet extension
6. View the confirmed hash in the Transaction Log tab

### Step 5: Register & Give Feedback
1. On first wallet connect, complete the **Onboarding Modal** (Name + Email + Rating)
2. Use the ⭐ floating button (bottom-right) anytime to rate your experience

## Troubleshooting

| Issue | Solution |
|---|---|
| Wallet not detected | Install Freighter or Albedo and refresh page |
| Transaction rejected | Approve in wallet pop-up within 60 seconds |
| Insufficient balance | Use Friendbot to get test XLM |
| "Failed to fetch" error | Check your internet connection |

---

## Mainnet Usage

For mainnet operations:
1. Switch network to **Mainnet** in the Header network selector
2. Ensure your wallet is funded with real XLM (minimum 2 XLM recommended)
3. All transactions use the deployed mainnet contract
